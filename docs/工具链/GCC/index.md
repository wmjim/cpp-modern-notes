# GCC

GCC-GNU项目 C 和 C++ 的编译器。

- [GCC 官网](https://gcc.gnu.org/)

## 常见有用选项

- `-Wall`：启用了有关构造的所有警告
- `-g`：以当前操作系统的格式生成调试信息，gdb 可以使用这些信息，使得 gdb 的调试工作更好。
- `-v`：显式输出详细的命令执行过程信息。
- `-l`：链接一个库，如：`-lm` 表示链接数学库，`-ldl` 链接 dl 库，这个库提供了对动态链接器的访问，允许程序在运行时加载共享库
- `-O`：优化代码，后面跟一个数字（如：`-O1`，`-O2`，`-O3`），表示不同的优化级别。
- `-std`：指定使用的语言标准，如 `-std=c99`，`-std=c++11`
- `-I`：添加包含文件的搜索路径，如：`-I/path/to/includes`
- `-L`：添加库文件的搜索路径，如：`-L/path/to/libraries`
- `-shared`：生成共享库
- `-static`：静态链接，使用静态库而不是动态库
- `-pthread`：用于支持多线程的程序，通常用于 C 程序中的 POSIX 线程
