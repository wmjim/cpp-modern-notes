# 注释

注释作为一种代码内文档。当插入到程序中时，它们实际上被编译器忽略；

它们仅供阅读源代码的人类用作笔记。

## 语法

| `/* 多行注释 */`     （1）        |
| ------------------- |
| `// 单行注释`            （2） |

（1）通常称为 **C 风格** 或 **多行注释**

（2）通常称为 **C++ 风格** 或 **单行注释**

注释在在预处理阶段之前， [翻译阶段3](https://cppreference.cn/w/cpp/language/translation_phases#Phase_3) 被从程序中移除，**方法**：将每个注释替换为单个空白字符。
